copied unchanged from [apache/ossie](https://github.com/apache/ossie) (Apache-2.0):

|---|---|---|
| `ossie-0.2.0.dev0.json` | `0.2.0.dev0` | `core-spec/ossie-schema.json` at commit `7205e15253ae3f340f8f191e978685006f5fa72d` (2026-10-22) |
| `osi-0.1.1.json` | `0.1.1` | `core-spec/osi-schema.json` at tag `osi-0.1.1-rc1` (commit `faf581054dcf7964d5fe0ceae7d6f415c8ce32a5`) |

A new version is added as a new file and a new row here, never by editing one of these.
